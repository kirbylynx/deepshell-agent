# DeepShell Agent v0.1.4 打包效率版本

> **产品：** DeepShell Agent
>
> **标语：** A desktop agent powered by DeepSeek Harness.
>
> **版本：** `v0.1.4`
>
> **版本性质：** 打包效率版本：按平台裁剪运行时、新增 Windows 免安装分发、平台原生菜单，以及有界的运行时清理加固。
>
> **状态：** **Windows x64 验收已登记**（WIN-01 至 WIN-13 在真实 Windows 11 x64 上实测）。本版本的 macOS arm64 侧打包工作在 macOS 阶段已实施并验证，但最终的联合回归（C0）、评审收口（C1/C2）与签名分发门禁仍未完成。**本文档不得被解读为已完成 macOS 验收。**
>
> **日期：** 2026-09-16

## 1. 版本范围

- **按平台裁剪运行时**（`REL-022`）：每个安装包只携带本平台实际执行的 Node 运行时；
- **Windows 免安装 ZIP**（`REL-023`）：可解压即用的第二种 Windows 分发形式；
- **平台原生菜单**（`DESK-023`）：macOS 保留应用菜单，Windows 使用 `File > Exit` 与 `Help > About DeepShell Agent`；
- **退出与卸载清理**（`REL-024`）：Windows 侧现在如实报告进程树终止失败；NSIS 卸载器在删除文件前运行受限维护命令，清理属于当前安装的残留；
- **包体积回归门禁**（`QA-011` 的包体积子范围）：tracked 基线、按平台构建输入 digest 与三方 manifest 体积门禁。

- `REL-027`：客户端渲染进程死亡仍未被检测与恢复；

- 构建主机上没有可用的依赖漏洞审计端点：npm 与 DSH 审计如实报告失败，仅 Rust 审计完成（零通告）；

## 7. 发布后复核修复

发布前对 Windows 阶段全部改动做了三轮复核，修复了一批正确性与可重复性问题；上述测量数据均在最终构建（`977da59`，win32-x64 源码输入指纹 `37937d93…`）上重新采集。

- **进程身份失败关闭加固**：卸载清理不再忽略身份校验失败、不再处理非 active 的所有权记录，PID 复用场景绝不会被终止（有专门回归测试注入该场景）；进程存活与路径校验区分"无法确认"与"已退出"，未知状态拒绝继续；所有外部 PowerShell/taskkill 调用均带超时。
- **可重复性**：新增 `package:windows:installed-tree` 命令编排"安装 → 捕获 → 卸载 → 环境恢复"，并把注册表/快捷方式恢复排在卸载完全结束之后（修复了恢复被卸载器后续步骤删除的竞态）。
- **边界与契约**：CI workflow 上传 Windows 平台 manifest（nsis 与 portable）；release staging 支持 `--require-assets` 供 combined staging 校验；卸载 hook 在静默安装下不弹窗、并在清理后等待文件句柄释放；About 元数据从 runtime-lock 读取 Node/DSH 版本而不再硬编码；包清单不再在 `resources` 重复整棵安装树。
- **第二轮复核**：installed-tree 编排在无法确认卸载完成时失败关闭（Abort 场景不再删除半安装目录、也不再把旧注册表覆盖回去伪装成"环境已恢复"），并拒绝 `runtime/staging/install-tree-v<version>` 之外的任意 `--install-root`；启动恢复在无法校验进程身份（例如 PowerShell 被策略禁用）时隔离记录并继续启动，退出与卸载路径仍失败关闭；`taskkill` 等待受调用方 deadline 约束，tar/cargo/strings 辅助调用显式带超时。重跑的 Windows 冒烟矩阵（干净状态、应用运行中、窗口关闭退出、强杀孤儿清理、卸载与注册表恢复）在最终构建上通过，同 commit 的 CI run `35218713142` 全绿。
- **第三轮复核**：NSIS hook 在 `ExecWait` 前清零并预置失败码（`ClearErrors` / `StrCpy $R0 15` / `IfErrors`），维护二进制无法启动时绝不会被误判为"清洁"；size gate、package report、release staging 与 runtime helper 的大文件哈希改为流式；package report 增加 portable ZIP 与磁盘归档的一致性比对；redaction 覆盖仓库根路径；installed-tree 卸载 settle 窗放宽到 90 秒（超时后补一次确认），portable tar 超时放宽到 30 分钟，杀软环境下的合法长耗时操作不再被误杀。重跑的真机冒烟矩阵在最终构建上全部通过（干净状态 0（两次）/ 应用运行中 13 / 窗口关闭退出无残留 / 孤儿清理 0 / 卸载并恢复注册表），同 commit 的 CI run `35245353581` 全绿。
