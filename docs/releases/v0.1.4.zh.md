# DeepShell Agent v0.1.4 打包效率版本

> **产品：** DeepShell Agent
>
> **标语：** A desktop agent powered by DeepSeek Harness.
>
> **版本：** `v0.1.4`
>
> **版本性质：** 打包效率版本：按平台裁剪运行时、新增 Windows 免安装分发、平台原生菜单，以及有界的运行时清理加固。
>
> **状态：** **Windows x64 验收已登记**（WIN-01 至 WIN-13 在真实 Windows 11 x64 上实测）。本版本的 macOS arm64 侧打包工作在 macOS 阶段已实施并验证，但最终的联合回归（C0）、评审收口（C1/C2）与签名分发门禁仍未完成。**本文档不得被解读为已完成 macOS 验收。**
>
> **日期：** 2026-09-16

## 1. 版本范围

- **按平台裁剪运行时**（`REL-022`）：每个安装包只携带本平台实际执行的 Node 运行时；
- **Windows 免安装 ZIP**（`REL-023`）：可解压即用的第二种 Windows 分发形式；
- **平台原生菜单**（`DESK-023`）：macOS 保留应用菜单，Windows 使用 `File > Exit` 与 `Help > About DeepShell Agent`；
- **退出与卸载清理**（`REL-024`）：Windows 侧现在如实报告进程树终止失败；NSIS 卸载器在删除文件前运行受限维护命令，清理属于当前安装的残留；
- **包体积回归门禁**（`QA-011` 的包体积子范围）：tracked 基线、按平台构建输入 digest 与三方 manifest 体积门禁。

## 5. 已知限制（如实记录）

- `REL-025`：隔离记录退休修复仅落在 Windows 侧；macOS 进程树仍带该缺陷；
- `REL-026`：文件拖拽仍被 Tauri 层吞掉；
- `REL-027`：客户端渲染进程死亡仍未被检测与恢复；
- 会话创建与 UI 级数据共享未做自动化验证，仍为人工项；
- 构建主机上没有可用的依赖漏洞审计端点：npm 与 DSH 审计如实报告失败，仅 Rust 审计完成（零通告）；
- macOS 最终联合回归（C0）与发布收口仍未完成。
