# DeepShell Agent v0.1.4 Packaging-Efficiency Release

> **Product:** DeepShell Agent
>
> **Tagline:** A desktop agent powered by DeepSeek Harness.
>
> **Version:** `v0.1.4`
>
> **Release nature:** a packaging-efficiency release: per-platform runtime trimming, a Windows portable (no-install) distribution, platform-native menus, and bounded runtime-cleanup hardening.
>
> **Status:** **Windows x64 acceptance is recorded** (WIN-01 to WIN-13 measured on real Windows 11 x64). The macOS arm64 side of the packaging work was implemented and verified during the macOS stage of this version, but the final joint regression (C0), the review closeout (C1/C2), and the signed-distribution gates are still pending. This document must not be read as a completed macOS acceptance.
>
> **Date:** 2026-09-16

## 1. Scope

- **Per-platform runtime trimming** (`REL-022`): each installer carries only the Node runtime its platform executes;
- **Windows portable ZIP** (`REL-023`): a second Windows distribution form that runs from an extracted folder;
- **Platform-native menus** (`DESK-023`): macOS keeps its application menu, Windows gets `File > Exit` and `Help > About DeepShell Agent`;
- **Exit and uninstall cleanup** (`REL-024`): the Windows side now reports a failed tree termination honestly, and the NSIS uninstaller runs a restricted maintenance command that removes residue belonging to the current installation before deleting files;
- **Package-size regression gates** (`QA-011`, package-size scope): tracked baselines, a per-platform source digest, and a three-manifest size gate.

## 5. Known limitations (recorded honestly)

- `REL-025`: the quarantined-record retirement fix landed on the Windows side only; the macOS process tree still carries the defect;
- `REL-026`: file drag-and-drop is still swallowed by the Tauri layer;
- `REL-027`: a dead client renderer is still not detected or recovered;
- session creation and UI-level data sharing were not exercised automatically and remain manual items;
- the dependency vulnerability audit has no working audit endpoint on the build host: the npm and DSH audits report the failure honestly, and only the Rust audit completes (zero advisories);
- the macOS final joint regression (C0) and the release closeout are still pending.

- `pnpm runtime:verify`, `pnpm profile:verify`, `pnpm package:compare` and `pnpm release:windows:check` green;
- exit matrices, cross-form single instance, no-trace portable launch, portable deletion and the uninstall matrices are recorded in the local acceptance evidence.
